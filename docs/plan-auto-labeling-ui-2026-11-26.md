# 自动识图 + 收藏区 / 导入界面重构：计划（2026-11-26）

目标：主人一次导入几十上百张图后，**不用懂任何概念**就能让图自动补上梗义、标签和图中文字；
识图随时能停、能接着跑，中途关面板、重启插件甚至重启宿主都**不丢已完成的结果**；
进度在任何页面一眼可见。同时把“收藏区”“导入”“新建区/分类”的界面一起理顺，做到看一眼就会用。

前提已验证（见 `roadmap-management-2026-11-24.md` 步骤 0）：宿主免费使魔模型能看图，
单张约 4 秒、约 700 token（含约 350 token 思考），`max_tokens` 需留 ≥1000。

---

## 一、核心原则：活在后台干，结果一张一存

1. **识图在插件后台跑，不在面板里跑。** 用插件已有的后台定时器（和回复选图同一机制）每拍处理一张。
   面板只负责“发指令”和“看进度”。关掉面板、切到别的标签页、去聊天，识图照常进行。
2. **每张图识别完立刻写回图库并存盘。** 不攒批、不等全部跑完。任何时候中断，最多丢正在看的那一张。
3. **队列状态记在每张图自己身上**（`label_state`），不另存一份容易和图库对不上的队列文件。
   插件或宿主重启后，按图库里的状态自然接着跑；暂停、今日已用量等少量开关存进 `labeling.json`。
4. **主人永远优先。** 只填空着的字段；主人改过的字段（`owner_edited`）一律不动。
   识别进行中主人改了某张图，写回时以主人为准。图在排队时被删，直接跳过。

### 每张图的状态

| 状态 | 含义 | 主人看到 |
|---|---|---|
| `none` | 没排队（老图或已有描述） | 无标记 |
| `queued` | 排队中 | 格子角上灰点“排队” |
| `working` | 正在看（同一时刻最多一张） | 蓝点“识别中” |
| `done` | 已自动补全 | 详情里“自动生成”小标签 |
| `failed` | 3 次都失败 | 红点“失败”，可一键重试 |

重启时如果有图停在 `working`，自动退回 `queued`。

## 二、主人怎么用（三条路径，都一步到位）

### 1. 导入后自动开始（默认）
导入页底部有一个默认勾上的 **“导入后自动识图”**。导入完成，结果卡片直接写：

> 已导入 37 张 · 正在自动识图 3 / 37 ▓░░░░░ 约 3 分钟　[暂停]

主人什么都不用点。不想自动跑就取消那个勾，之后在概览里手动开始。

### 2. 概览里补以前的图
概览“需要处理”里原来的“N 张图没有梗义和标签”，按钮从“去补描述”改成 **“自动识图”**，点一下就排队开跑。
旁边保留“手动补”（跳到图库的缺描述筛选）。

### 3. 单张重新识别
图片详情里加 **“重新识别”**：只重做这一张，主人改过的字段仍然保留。

## 三、能打断、能续接

| 操作 | 效果 |
|---|---|
| 暂停 | 当前这张看完就停（最多约 5 秒），已完成的全部保留 |
| 继续 | 从下一张接着跑 |
| 停止并清空队列 | 没跑到的图退回“没排队”，已完成的保留 |
| 重试失败的 | 失败的图重新排队 |
| 关面板 / 切标签页 | 不影响，后台继续 |
| 重启插件 / 宿主 | 自动接着跑（重启前是暂停的就仍然暂停） |

### 自动暂停（都给出一句人话 + 怎么办）

| 原因 | 提示 |
|---|---|
| 免费额度用完 | “今天的免费额度用完了，明天会自动继续” |
| 达到每日上限 | “今天已识别 300 张（每日上限），明天自动继续；可在设置里调高” |
| 模型没绑定 / 不能看图 | “识图模型不可用：……”，附“测试识图”按钮 |
| 宿主不支持 | “当前宿主版本不支持识图”，不报错、不排队 |
| 连续 5 张失败 | 暂停并提示，避免空耗额度 |

## 四、进度可视化（任何页面都看得到）

1. **顶部进度条**（只在有任务时出现，四个标签页都显示，就在开关那一行下面）：
   `正在识图 12 / 37 · 约 2 分钟 · [暂停]`；暂停时变成 `已暂停 12 / 37 · [继续] [清空]`；
   自动暂停时显示原因。
2. **概览进度卡**：大一点的进度条、正在看的那张缩略图、成功 / 失败 / 剩余数，以及“查看本次结果”。
3. **图库格子角标**：排队 / 识别中 / 失败；左侧目录多一个“识别失败”筛选（有失败时才出现）。
4. **完成提示**：跑完后进度条变成 `识图完成：35 张成功，2 张失败 [重试失败的] [查看结果]`，
   主人点掉之前一直保留。

面板在有任务时每 2 秒刷新一次进度；没任务时不轮询。剩余时间按最近 10 张的平均耗时估算。

## 五、收藏区 / 导入 / 新建：界面重构

### 现在的问题
- 收藏区藏在一个下拉框加“管理收藏区”折叠里，“浏览哪个区”和“猫娘用哪个区”很容易混淆；
- 新建区在“管理收藏区”里，新建分类在分类目录底部，导入页又有一套区 / 分类选择，三处做法不一样；
- 导入页没说清导入后会发生什么。

### 新设计

**图库左栏改成两层目录：区 → 分类**

```
收藏区
  ● 官方收藏      190   ← 实心点 = 猫娘正在用
    我的收藏       37
  ＋ 新建收藏区
───────────
分类（我的收藏）
  全部          37
  开心与庆祝     12
  …
  缺描述         5
  识别失败       2
  ＋ 新建分类
```

- 点区 = 浏览这个区，**不会**改变猫娘用哪个区；
- 右侧区标题行：`我的收藏 · 37 张　[让猫娘用这个区]　[⋯]`，正在用的区显示“猫娘正在用”；
  `⋯` 里是改名、改说明、删除（删除保留 3 秒确认）；
- 左栏顶部一句常驻说明：“猫娘只从带 ● 的区里挑图”；
- 窄屏：区变成顶部下拉，分类仍是横向滚动条。

**新建区 / 新建分类用同一个就地小表单**：名字（必填）+ 一句说明（可选，旁边注明“选图模型会参考这句话”）。

**导入页改成三步，从上到下读一遍就懂**

```
① 放到哪里     区 [我的收藏 ▾]   分类 [未分组 ▾]   （默认 = 图库里正在看的区和分类）
② 选择图片     [ 把图片或 zip 拖到这里，或点击选择 ]
③ 导入之后     [✓] 自动识图，补上梗义、标签和图中文字（免费模型，约 4 秒一张）
```

导入完成后同一页出现结果卡（导入几张、跳过几张重复、识图进度）。
“备份与维护”（导出、体检）留在导入页最下方，默认收起。

## 六、写回规则

- 模型输出：`caption`（一两句：这张图在聊天里表达什么）、`tags`（4–8 个）、`visible_text`、
  `category_fit` 与 `suggested_group`（只能从当前区已有分类里选）；
- 只填空字段；`owner_edited` 里的字段不动；新增 `auto_fields` 记哪些字段是自动写的，
  主人改了其中一个，该字段从 `auto_fields` 移到 `owner_edited`；
- 建议分类：图在“未分组”时直接移过去；已有分类的只在详情里提示“模型建议放到 X”，不自动挪；
- `desc`（短名）为空或只是文件名时，用 caption 的前一小句补上；
- 解析失败重试 1 次，仍失败计一次失败；同一张最多 3 次。
