# 表情包管理 0.9.7

本次起，支持回复完成通知的宿主中，由插件在猫娘说完话后自己选图，
并把图片挂到那条回复末尾；选图模型默认跟随宿主的使魔模型，无需另外配置。
管理面板也重新整理为“概览 / 图库 / 导入 / 设置”四页。
插件 ID 保持 `sticker_manager`，只在 GitHub 发行，不通知插件市场。
`0.9.5`、`0.9.6` 未单独发行，其改动一并包含在本版中。

## 更新

### 新面板

- **概览**：打开面板先看选图是否正常、配图概率、当前使用区和收藏数；
  “需要处理”列出发送已关闭、选图异常、缺描述的图和空的使用区，可一键跳过去处理；
  下方显示最近发出的图和本次运行统计。
- **图库**：宽屏左侧是分类目录（含“缺描述”筛选和新建分类），点图在右侧看详情，
  不离开列表；窄屏详情整页显示，手机宽度下分类目录变为横向滚动条。
- **选择模式**：平时点图看详情，点“选择”后才勾选和批量操作。
- **分类**：分类说明直接显示在标题下，编辑说明、删除分类、添加图片放在标题行。
- **导入页**：图片和 zip 套图包导入集中在一处，可先选目标区和分类；
  导出套图包、体检与修复也在这里。

### 选图与发图

- **回复后选图**：主模型只负责说话；回复结束后插件把用户的话、猫娘的回复和候选图交给
  “回复配图选图”（`eager_attachment`）判断，选中就登记到原回复末尾，不贴切就跳过。
  这条路径会撤下主模型的发图工具和配图提醒，不续写正文。
- **免配置模型**：支持插件模型跟随宿主的 N.E.K.O 在安装或更新时，把该用途自动绑定到
  宿主的使魔模型，可直接使用宿主免费模型。已有的手动绑定保留。
- **更快的选图**：请求末尾预填答案开头，宿主免费模型实测由 2–16 秒降到 1.2–2.6 秒；
  供应商不接受预填时自动改用普通请求。
- **按概率配图**：矜持 / 自然 / 爱发三档、每轮配图开关和补图轮数退出面板，
  改为一个“配图概率”滑块（默认 50%，平均约两轮一张）。每条回复先掷概率，
  命中才调用选图模型，未命中不占模型额度。发送冷却默认改为 0 秒。
- **自动降级**：选图模型持续不可用（未绑定、使魔模型未配置、免费额度用完等，
  或连续 3 次失败）时，自动交还主模型发图工具；每 10 分钟重试，面板“测试选图”
  通过后立即恢复。各类模型错误在面板分别给出可操作的提示。
- **权限声明**：`plugin.toml` 写明插件需要的权限与用途，供宿主检查与后续授权使用。

## 升级须知

从本次 GitHub Release 下载 `sticker_manager.neko-plugin`，在插件管理中覆盖导入。
图库、条目 ID 和使用记录保留；不要卸载清除数据。

**升级后首次启动会把发送频率相关设置统一改为新默认值**：配图概率 50%、
发送冷却 0 秒、关闭每轮配图。只改写一次，之后在面板里的修改会保留。

## 兼容

- 回复后选图需要宿主提供回复完成通知（N.E.K.O #3585）；
  免配置模型需要宿主支持插件模型跟随（#3741）。
- 旧宿主保持原来的主模型工具发图，不受影响。
- 选图调用计入宿主使魔模型的用量；使用免费模型时与使魔任务共用每日免费额度。

## 已知限制

- 不保证每轮都发图：概率未命中、用户要求纯文字、严肃话题、没有贴切候选或冷却中都会跳过。
- 图片在文字出来后约 1–3 秒补上；宿主回调上限 15 秒，插件选图超过 12 秒放弃本轮。
- 宿主几乎把所有 4xx 错误都视为“请求被拒”，首次请求因其他原因失败时也会关闭预填，
  直到插件重启。
