`0.9.0` 是维护者选定的版本重定号和导入测试候选版；准备阶段未提交、推送或上架。
维护者随后授权提交推送，仍不创建版本标签或发布市场版本。

不比较版本号大小，但安装版导入与兼容性仍需维护者自行验收。

## 项目与边界

插件通过宿主公开 SDK 注册面板、库管理入口和 `sticker_list` / `sticker_send` 主聊天工具。
`core` 是纯业务规则，`services` 负责持久图库、发送、提醒与诊断，`ui` 是 Hosted TSX 面板。
运行时不新增第三方 Python 安装依赖。开发素材构建与测试使用 Pillow；
运行时缩略图可利用宿主提供的图片库，缺失时有降级路径。

本次只修改插件文件。宿主源码和安装版只读；检查和元数据探测使用独立快照、隔离数据根、
文件写入围栏及网络连接围栏，不向运行中的宿主发请求，不安装测试插件或改用户配置。
真实日志目录已通过目录列表确认，未把用户聊天日志复制进插件或发行包。
Windows 默认日志位置是 `%LOCALAPPDATA%\N.E.K.O\logs`，插件日志在其 `plugin` 子目录。

## 隐私说明

总开关默认关闭。管理面板仍可整理库；猫娘看目录、工具发图和提醒注入需用户开启总开关。
插件会通过宿主消息总线观察用户轮次，在本地判断提醒条件；这不是聊天备份功能。
开启兼容排队发送时还会读取宿主主日志的新增回复完成记录；默认即时工具发送不依赖它。
本机 HTTP 仅用于当前角色、工具注册表和健康状态诊断，不是外部遥测或插件更新服务器。

用户导入的图片、说明、分类与使用台账保存在宿主选定的独立用户数据区。
导出套图包含图片和说明/标签/分类；导出前应自行确认这些内容是否适合分享。
检索词和可选配文不应原文写入插件诊断日志，已有隐私哨兵测试覆盖正常调用路径。
错误堆栈与路径仍可能包含本机信息，提交 issue 时需要脱敏，不要公开整个用户数据目录。
