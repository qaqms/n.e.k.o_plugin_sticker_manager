# 表情包管理 (sticker_manager)

给她一个自己的表情包收藏间。

**开张即存货**：随包内置 190 张官方收藏（全部保动画的贴尺 gif），首次启动自动收进「官方」区——
只播一次，拆掉后面板 tab 尾可一键「恢复官方收藏」（v0.12.0 J-2）。

主人先选**区**（分类的上层：J-1 三层「区→分类→图」，她只感知当前激活的那个区），
再**建分类**（名字 + 一句“什么时候用这一类”），点分类块头的「收图进这一类」
把图收进来（想逐图补什么，点开图在聚焦卡里改）；猫娘通过
`sticker_list` / `sticker_send` 两个工具在对话里自主挑一张发出去。
每次发送（含失败的尝试）都记进使用台账——台账在幕后供跨轮去重与最近爱用排序，面板不再展示明细。

## 能力面

| 面 | 内容 |
| --- | --- |
| 管理入口 | `add` / `update` / `remove` / `send` / `list` / `preview` / `history` / `switch` / `repair` / `import_inbox` / 直传三入口 `import_upload_start`→`chunk`→`finish` / `group_create` / `group_remove` / `group_set_desc` / `batch_update` / `batch_remove` / `zone_create` / `zone_rename` / `zone_set_desc` / `zone_activate` / `zone_remove`（J-1：区是分类的上层，内部 id 引用所以改名白送） / **`zone_restore_official`（J-2：官方区被拆后的补救，长任务走 120s 尺）** / **`set_eagerness`（v0.14.0：配表情积极度三档）** |
| 分类优先（轮 I） | 默认空库什么都没有：先在区内点「新建分类」写名字（必填）+“什么时候用这一类”（可留空），建完就能往它里收图。**收图不问逐图字段**（描述交空串，目录正文按回落尺取分类说明），想逐图改就点开图用聚焦卡。**删分类 = 连带删它里的图**（1C 拍板），确认里先摊精确张数 |
| 区（J-1） | 三层「区→分类→图」：分类名**全库唯一**（跨区也算——她按名字选图，一个名字不能两个家）；**她只感知激活区**：目录/发图/检索/注入全走 `active_pool()`，其余区整体隐形；主人可浏览任意区，但所有写入（建类/收图/导入）落正在看的区。拆区连带拆全部分类与图（最后一个不许拆；面板确认摊服务端张数 + **3 秒防误删闸**，纯前端）。旧库 load 即迁入默认区「自制区」，无需手工迁移 |
| 官方区（J-2/J-3） | 官方收藏 190 张随包内置（`official/official_pack.zip`，manifest v3 + `pack_version`）；**已分好 22 类、逐张标了梗义**——她看到的目录正文是「一切都好（冒烟版）」这种话，不是文件名；首启播种只播一次（`official_seeded` 台账，脏包不盖章下拍重试）；区的真身是 `builtin` 位，同名手建区就地收编；**空库才默认激活官方区，旧库升级不抓台**；官方区不在册时 tab 尾可一键「恢复官方收藏」（`zone_restore_official`，吃指纹查重不重入）；tab 带「官方」徽章。**标签随包下发（J-3）**：包版本比库里新（catalog 顶层 `official_pack_version`）时，按内容指纹把官方区条目的文本刷成包里的版本——不重进图、不动启停与台账；主人改过的措辞（desc/caption 任一）整块归主人不被包消音，分类与标签照刷 |
| 轻打标 | 逐图文本全可选：一句**分类说明**就是她看到的分类目录正文；目录行正文回落 `梗义>描述>分类说明>未标注`，不造假描述；逐图归类**只能从已有分类里选**（Select，不再是自由输入——手打新名字会静默立一个没说明的分类）；批量勾选即可加/删标签、移入分类、启停、删除 |
| LLM 工具 | `sticker_list`（看目录）、`sticker_send`（按 id / 分类 / 关键词发），带**注册心跳**：宿主/main_server 重启后静默缺席的工具每 5 分钟被点名补挂；`sticker_send` 的描述随**积极度档位**重挂（v0.15.0） |
| 面板 | hosted-tsx：**区 tab（新建/改名/说明/激活/拆区 3 秒确认）** + 分类分区墙（一格一图 + 就地聚焦卡）、新建/删分类、逐分类收图、总开关、**配表情积极度三档**。**零覆盖层弹窗**（平台坑，见 DESIGN 陷阱 20）；v0.10.2 起「她最近用过的」台账卡退场（后端台账保留，仍供去重/排序）；v0.14.1 起「她在跟谁说话」能解析出来（面板按钮不再报 `no_target`，见陷阱 27） |
| 格式 | png / jpg / gif / webp（只认文件头），单张 ≤8MiB；gif 动图保动画直发 |
| 批量入库 | 分类头「收图进这一类」（多选，目标分类就是这一块，单轮≤64 张）；**「导入」选 `.zip` 直传**（v0.6.0 分块上传，manifest 随行带描述/标签/套图/梗义/**分类说明**）；高级旁路（v0.10.3 起面板无按钮无提示）：把图/包放进 `data/library/inbox/`，服务端 `import_inbox` 入口照旧整批收 |
| 防重复 | 入库记内容指纹（sha256），同图再传如实拒绝；旧图 lazy 回填 |
| 库体检 | `repair` 入口/面板按钮：清掉丢图的条目与孤儿文件，补旧条目指纹 |

## 开关语义

`[sticker_manager].enabled = false`（默认，fail-closed）：她不发图、看不到目录，
但库的收藏/编辑/删除照常可用。总开关在面板顶部或 `switch` 入口切换。

## 频控与容量

- 同一角色卡两次发送之间默认冷却 20 秒（`[sticker_manager.send].cooldown_sec`）；
- **两级目录选图**：`sticker_list` 无词时先报【套图分类】再报条目，带 `group` 只看那一类；
  `sticker_send(group=)` 只拍板“这类调性对”，组内先过近期去重尺再随机选一张（id > group > query）；
  **零张的分类不出现在她的目录里、也不能被她选去发**（轮 I：分类是管理概念，不是发送目标）；
- **跨轮去重**：她自主选图时，同一角色卡最近 5 张成功发过的不再出现
  （`recent_dedup_count`，0=关；台账源，重启不失忆）；主人点名要再看某张时
  她可用 `sticker_send(force=true)` 绕行（冷却仍生效）；
- **配表情积极度**（v0.14.0 三档 Select：矜持 / 自然 / 爱发；v0.15.0 起同时写进两处）：只管**她有多想配图**——
  ① 存在感注入的意愿段；② `sticker_send` 的**工具描述**（每轮都在场，这才是常驻面）。
  默认「自然」与 v0.13.0 的行为一字不差。切档当场生效（面板 `set_eagerness` → 重挂工具描述），
  手改 toml 则在 `config_change` 时跟上；想让她更常配图选「爱发」，想安静选「矜持」；
- **存在感注入按话轮走**（v0.16.0）：她每开一轮（`bus.memory` 里的 `user_message` 前进）才是
  一个决策点，不再是"每小时注一次、剩下 73% 的轮次她没被提醒过"。节奏三键在
  `[sticker_manager.awareness]`：`inject_mode`（`interval_n` 默认 / `every_user_message`）、
  `inject_interval_n`（默认 3 轮）、`min_interval_sec`（默认 60 秒地板，防连珠炮刷屏）。
  面板上只有读数（`节奏` / `驱动`），旋钮在文件里；总线读不通时自动退回
  `interval_sec` 的挂钟降级路径，`驱动` 那格会如实显示"降级时钟"；
- **概率闸门**：`send.probability` 控制她发图意愿到实际放行的比例（默认 1.0=关）。
  同一角色卡一个复用窗口（`probability_reuse_sec`）内只掷一次判定，不叠加惩罚；
  **闸门与积极度是两把尺**：闸门拒她已下的决定，积极度改她想不想发——互不越界；
- ≤256KiB 的图走内联通道（保留原字节与 gif 动画），更大的静态图走宿主上传换 URL；
  动图超过内联预算会**如实拒绝**而不是被压平成 JPEG；
- 给模型看的目录默认最多 80 条（按最近使用排序），台账保留 200 条。
